- Source files: `site/fonts/D2Coding-Regular.woff2` and `site/fonts/D2Coding-Bold.woff2`

The site prefers the reader's installed Consolas for Latin code. D2Coding supplies Hangul and other glyphs that Consolas does not support. If Consolas is unavailable, D2Coding renders the code. The font files are served with the site; no system font installation or external font service is required.

The upstream WOFF2 binaries contain the ligature build. Code styling disables ligatures so operators remain visually separate.
