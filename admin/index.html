          설정

          공개 사이트와 로컬 관리 도구의 경계를 확인합니다.

          관리자 접속

          127.0.0.1에만 연결합니다. 외부 인터넷과 같은 네트워크의 다른 기기에서는 접속할 수 없습니다.

          공개 배포

          GitHub Pages에는 생성된 공개 사이트 파일만 올리고, 이 관리자 폴더는 빌드와 저장소 배포 대상에서 제외합니다.

          문서 편집

          Obsidian에서 작성합니다. 관리자 화면은 상태 확인과 발행 점검을 담당합니다.

          Cloudflare 통계

          .env.local의 읽기 전용 API 설정으로 Site Tag를 찾고 페이지별 조회수를 가져옵니다. 토큰과 계정 ID는 Git에 커밋하지 않습니다.

          외부 관리자

          나중에 밖에서도 접속해야 한다면 별도 도메인과 인증 계층을 추가합니다.
